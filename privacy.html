プライバシーポリシー

制定日：2026年10月2日

このプライバシーポリシーは、YouTube チャンネル「知っ得エビデンス」（以下「当チャンネル」）の運営者が使用するアプリケーション「shittoku-uploader」（以下「本アプリ」）における、情報の取り扱いについて定めるものです。

1. 本アプリの目的

本アプリは、当チャンネルの運営者が、自身の YouTube チャンネルに動画をアップロードし、公開日時やサムネイルなどを設定するためだけに使う、運営者専用のツールです。一般の利用者に提供するものではありません。

2. YouTube API サービスの利用

本アプリは YouTube API サービスを使用しています。本アプリを利用することにより、YouTube 利用規約に同意したものとみなされます。また、Google による情報の取り扱いについては、Google プライバシーポリシーをご確認ください。

3. 取得する情報

本アプリは、運営者が Google アカウントで許可した範囲で、次の情報にアクセスします。

  • 運営者のチャンネルの基本情報（チャンネル ID・チャンネル名）
  • 運営者のチャンネルの動画情報（タイトル・説明・公開設定など）
  • API を使うための認証情報（アクセストークン・更新トークン）

視聴者の個人情報や、運営者以外のユーザーの情報を取得することはありません。

4. 情報の利用目的

取得した情報は、運営者自身のチャンネルへの動画のアップロード、公開予約、サムネイル設定、投稿状況の確認のためだけに使います。広告や分析など、それ以外の目的には使いません。

5. 情報の保存と共有

認証情報は運営者のパソコン内にのみ保存し、外部のサーバーには送信しません。取得した情報を第三者に販売・提供・共有することはありません。

6. アクセス権の取り消し

本アプリに与えたアクセス権は、Google アカウントの「サードパーティ製のアプリとサービス」のページから、いつでも取り消せます。取り消すと、本アプリは以後チャンネルにアクセスできなくなります。

7. ポリシーの変更

このポリシーは、必要に応じて変更することがあります。変更した場合は、このページに掲載した時点で効力を生じます。

8. お問い合わせ

このポリシーに関するお問い合わせは、YouTube チャンネル「知っ得エビデンス」の動画のコメント欄からお寄せください。
